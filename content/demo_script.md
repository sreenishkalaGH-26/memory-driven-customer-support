# Live demo script (about 2 minutes)

Setup (before judges arrive): Hindsight running, `.env` filled, `streamlit run app.py`, sidebar shows 🟢, click **Start a fresh demo run**, select **Priya Sharma**.

**Say:** "Customer support agents usually know what is in the current conversation, but the problem starts when the customer comes back later."

**Step 1 – Interaction 1**
Type: `My payment is failing whenever I use the Android app.`
**Say:** "Before replying, the app calls Hindsight recall. This is a new customer, so nothing comes back, and the agent troubleshoots normally."
Point at: 🔎 recall line, then the reply.

**Step 2 – Retain**
Point at: "🧠 Memory retained in Hindsight".
Type as the customer: `I cleared the cache and restarted the app, and the payment worked.` Click **Retain resolution**.
**Say:** "That exchange and the confirmed fix are now stored in Hindsight, in this customer's memory bank."

**Step 3 – Later**
**Say:** "Later, the same customer returns and simply says:"
Type: `My payment is failing again.`

**Step 4 – Recall**
Point at: "🧠 Hindsight Memory Recalled" and the memory panel.
**Say:** "Hindsight recall returned the earlier Android payment issue and the fix. This panel shows exactly what was passed to the agent."

**Step 5 – Personalized reply**
Point at the reply.
**Say:** "The agent doesn't ask which device she uses. It builds on what happened before."

**Step 6 – Before vs After (optional, 30 seconds)**
Open the Before vs After tab, run the comparison.
**Say:** "Same model, same message. Left has no memory; right has Hindsight recall."

**Close – say exactly:**
"The important part is not that the agent can answer a support question. The important part is that it can remember what happened before and use that experience when the customer returns."

Only say what you saw on screen. If a reply doesn't reference the earlier issue, say so and show the recalled memory panel instead of claiming it did.
